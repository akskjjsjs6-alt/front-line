# Intro footage

Clips placed here play behind the cards of the opening sequence (the `main` cut in `js/intro.js`).
Until a clip exists, a drawn stand-in is used. MP4 (H.264), landscape, no sound needed, 4-10 seconds.

| File | Plays behind |
| --- | --- |
| `march.mp4` | the red IMPERIUM end card |
| `navy.mp4` | 5 JUNE 1900 |
| `speech1939.mp4` | 1 SEPTEMBER 1939 |
| `speech2003.mp4` | 20 MARCH 2003 |
| `china.mp4` | the China silhouette |
| `nuke.mp4` | TOTAL WAR (optional; a drawn blast is used otherwise) |

Only add footage the project has the right to use (public-domain archive film, or licensed clips).
